# Enums

التعدادات الخاصة بالنطاق الأكاديمي.

## الملفات المتوقعة

- `AcademicYearStatus.php` - حالات السنة (pending, active, closed, archived)
- `TermStatus.php` - حالات الفصل (pending, active, completed)
