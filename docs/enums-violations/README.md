## تقرير مخالفات استخدام Enums

هذا المجلد يحتوي على توثيق محدث لمخالفات استخدام الـ Enums في المشروع، مقسّم حسب الدومين.

- `finance.md` – مخالفات دومين التمويل (Finance)
- `hr.md` – مخالفات دومين الموارد البشرية (HR)
- `academic.md` – مخالفات دومين الأكاديميا (Academic)
- `shared.md` – ملاحظات على الدومين المشترك (Shared)

يتم تحديث هذه الملفات عند إجراء مراجعات معمارية أو عند إضافة Enums جديدة.
